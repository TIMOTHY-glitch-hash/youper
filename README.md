# youper

A collaboration project — starter repository for the youper project.

Quick start

1. Clone the repo:

   git clone git@github.com:TIMOTHY-glitch-hash/youper.git
   cd youper

2. Pick a branch and work locally:

   git checkout -b feature/short-description
   # make changes, run tests, commit
   git add .
   git commit -m "feat: add ..."
   git push -u origin feature/short-description

3. Open a Pull Request on GitHub and request reviews from CODEOWNERS.

Repository structure

- .github/: GitHub configuration (issue templates, PR template, workflows)
- README.md: this file
- LICENSE: project license
